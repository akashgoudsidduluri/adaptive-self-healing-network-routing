DYNAMIC PATH SELECTION

Intelligent bypass around congested corridors.

Static routing algorithms like naive OSPF send all traffic across the lowest nominal hop count until links saturate. NetAdapt measures live link utilization and dynamically inflates costs on loaded links.

  • ✓
    Cost Function: Combines propagation delay, queue occupancy, and nominal bandwidth.
  • ✓
    Oscillation Prevention: Hysteresis smoothing prevents unstable packet flapping between routes.
  • ✓
    Per-Flow Coherence: Ensures TCP packets maintain packet order during path migrations.

HIGH AVAILABILITY TOPOLOGY

Zero downtime when infrastructure fails.

When cable cuts, switch reboots, or interface errors occur, NetAdapt detects neighbor reachability drops in milliseconds. State is disseminated across all participating nodes to converge on alternate routes without administrative intervention.

  • ✓
    Sub-50ms Detection: Fast BFD-style hello intervals detect severed connections immediately.
  • ✓
    Loop-Free Convergence: Strict topology invariants guarantee no transient micro-loops occur during recovery.
